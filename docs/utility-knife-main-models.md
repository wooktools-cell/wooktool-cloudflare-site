# Utility knife SEO main-model shortlist

## Purpose

This is the 20-model source queue for future indexable utility-knife pages. It replaces a volume-first approach: each selected model represents a distinct buyer use case, construction direction, or blade format. Models that reuse an image or only change a code stay in the RFQ catalogue and do not receive standalone search pages.

## Selection rules

- Use the approved source catalogue for model code, weight and packing data; do not publish an unsupported material, blade, lock or safety claim.
- Build one dedicated page only when the page can show a distinct product image, model-specific specifications, applications, FAQ and an RFQ path.
- Keep similar colour, weight or packaging variants under the most relevant parent model unless they have a different buyer use case.
- Do not display reference unit prices on public SEO pages.
